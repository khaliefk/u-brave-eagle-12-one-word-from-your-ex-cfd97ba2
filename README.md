## The entry

`Placeholder`

One word, the word an ex would use to describe you. It lands instantly: you were never the main event, just filling a gap until something better came along. It stings because it is true, and no near synonym keeps its edge.

## How it works

`main.py` writes the single word to `/output/entry.txt` (11 characters, no trailing newline). Before writing, it checks the word against the competition gate: UTF-8 text, 1 to 24 characters, not only whitespace, exactly one word.

Run it with:

```sh
python3 main.py
```
